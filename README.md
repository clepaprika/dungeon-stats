# dungeon-stats
Minecraft mod to check your dungeon stats on Newwind

Recent changes include crafting embers into deggs and teams support

/dstats help #lists all commands
/dstats settings #open the customization pannel

Future ideas : dstats bestplayer : lists the players with the mosts leaderboard times (with multiplier for best times and higher levels...), list the best dungeons (/dstats bestdungeon), make the HUD more customizable (show all time combined), display the comparaison with leaderboard as we kill the last mob.
