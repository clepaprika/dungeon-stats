# dungeon-stats
__Minecraft mod to check your dungeon stats on Newwind__

Recent changes include crafting embers into deggs and teams support

/dstats help #lists all commands

/dstats settings #open the customization pannel 

The mod can :
- Read the leaderboard times when you go through the dungeon pannel
- Show a quick summary of a dungeon when typing /dungeon 46 (including best times, your personnal best time...)
- Keep track of your earnings in dungeons and how many dungeons you ran (total and per level)
- A cool HUD (its cool)
- Compare your time with the leaderboard and tell you straight ahead if you got a leaderboard time or not
- Count how many mobs you killed on the current dungeon
- Tell you if you missed chests
- Display the leaderboard in the HUD
- Hide the dungeon map (toggle option in /dstats settings)
